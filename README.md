# 📈 Institutional IPO Prediction Engine (Indian Mainboard)

## Executive Summary
This repository houses an automated, end-to-end Machine Learning pipeline designed to evaluate Indian Mainboard Initial Public Offerings (IPOs). Built specifically as a defensive screening tool for capital allocation, the engine filters out high-risk listings and identifies high-conviction "Bumper Pop" opportunities. 

The system operates autonomously via GitHub Actions, scraping live market data, enriching it with macroeconomic indicators, retraining a two-stage hybrid ML engine, and outputting proprietary datasets to feed a Power BI visual terminal.

## 🏗️ System Architecture & MLOps Pipeline

1. **Automated Data Ingestion (Bypassing Anti-Bot Security)**
   - Utilizes `undetected-chromedriver` and Selenium to bypass Cloudflare protections on financial data portals.
   - Cleans and scopes historical data, explicitly filtering out pre-ASBA (pre-2010) and SME IPOs to prevent regulatory noise from skewing the model.

2. **Macro-Economic Feature Enrichment**
   - Integrates 16 years of historical **Nifty 50 momentum** and **India VIX** volatility metrics.
   - Mathematically models institutional demand (QIB) using logarithmic scaling to handle extreme market outliers.

3. **Hybrid Machine Learning Engine**
   - **Stage 1 (Signal Classification):** A `RandomForestClassifier` trained to predict the binary probability of a positive listing. Optimized strictly for **Precision** rather than accuracy to minimize false positives and protect downside risk.
   - **Stage 2 (Magnitude Regression):** A `GradientBoostingRegressor` trained to predict the exact listing gain percentage. Evaluated using **Huber Loss** to maintain baseline accuracy while resisting extreme 150%+ market anomalies.

4. **Continuous Integration / Continuous Training (CI/CT)**
   - Fully automated MLOps pipeline using `GitHub Actions` (`weekly_pipeline.yml`).
   - Executes every Sunday at midnight: triggers the scraper, retrains the models, and pushes the updated `.pkl` and `.csv` deliverables directly back to the repository.

## 📂 Repository Structure
* `scrape_full_market.py` / `scrape_ipos.py`: The extraction and macro-enrichment engine.
* `train_model.py`: The core ML training script that generates the classification and regression models.
* `predict.py`: Execution script for scoring upcoming unlisted IPOs.
* `ipo_prediction_model.pkl`: The serialized, production-ready model weights.
* `MASTER_IPO_DATASET.csv`: The cleaned, enriched historical training data.
* `Feature_Importance_Report.csv`: Quantitative proof of feature weightings (e.g., QIB subscription dominance).
* `IPO_Predictions_Dashboard.csv`: The final output dataset feeding the external Business Intelligence layer.

## 📊 Business Intelligence & Visualization
The data generated by this repository connects to a custom-built Power BI dashboard. Designed with a dark-mode fintech UI, the terminal provides an Institutional Conviction Matrix (Scatter Plot) and an actionable, color-coded screener for rapid portfolio decision-making.
